# everyshape

Declarative document model for everybase — shapes, slots, and descriptors.

## Install

```bash
pip install everyshape
```

## Usage

```python
from everyshape import ShapeBase, ShapeMeta, SlotDescriptor
```

## Development

Part of [everybase](https://github.com/everyabc/everybase).

```bash
make test-pkg PKG=core/everyshape
```
