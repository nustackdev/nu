# everybase

**Term Programming platform for Python.**

## Structure

- protocols: 3 core protocols (term, flow, link)
- fabrics: ready operations (kv, sql, notion, etc)
- everybase: the platform

## Installation

```bash
pip install everybase
```

## Three Protocols

### everyterm - Data Topology

What exists and how it relates.

- **Ref**: Location
- **Computation**: Expression

### everyflow - Execution Topology

What happens and in what order.

- **Flow**: Unit of execution
- **Runtime**: Execution context

### everylink - Network Topology

Where processes live and how they connect.

- **Link**: Connection unit
- Distributed coordination primitives
