# Loomi

**Build composable Python apps from declarative state-bound operations.**

```python

class MyApp(AsyncApp):
    ...

    def define(self) -> AsyncOperation:
        return self.ex.Sequence(
            self.ex.Retry(
                self.ex.Function(self.get_data),
                retry_delay=5,
                backoff=2,
            ),
            self.ex.Map(self.process_item, map_path=("data", "items")),
            self.ex.Function(self.save_data),
            self.ex.Branch({
                True: self.ex.Function(self.notify_slack_success),
                False: self.ex.Function(self.notify_slack_failure),
            }, condition_path=("result", "success")),
        )

```

## What is Loomi?

**Loomi changes how Python apps work - control flow and state become one thing through composable, declarative, state-bound operations.**

**This means:**
1. Build apps from basic operations - functions, sequences, loops, ...
2. Combine apps to make bigger apps
3. Operations are bound to state they need to make decisions - choosing paths, repeating steps, ...

**You get:**
1. 10x easier to design and build apps
2. 10x easier to maintain and extend apps
2. 10x upgraded robustness and reliability

**Superpowers included:**
- Concurrency out of the box without spaghetti code
- Resumable, reproducible executions with persistent fast state
- UI to visualize executions and state
- Debugging and profiling tools
- LoomiSTD and LoomiVerse - a collection of reusable apps
