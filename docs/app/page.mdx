# Loomi

**Build composable Python apps from declarative state-bound operations.**

```python
class PriorityTaskApp(AsyncApp):
    """A priority-based task processing"""

    def define(self) -> Operation:
        return self.ex.Sequence(
            # Initialize priority queues
            self.ex.Function(self.init_state),
            # Loop through tasks until all are processed
            self.ex.Loop(
                # Process tasks in priority order
                self.ex.Branch(
                    {
                        # When high priority tasks exist, process those first
                        True: self.ex.Map(
                            self.ex.Function(self.process_high_priority_task),
                            items_path=("_", "tasks", "high_priority"),
                            max_concurrency=5,
                        ),
                        # Otherwise process low priority task
                        False: self.ex.Map(
                            self.ex.Function(self.process_low_priority_task),
                            items_path=("_", "tasks", "low_priority"),
                            max_concurrency=5,
                        ),
                    },
                    condition=self.has_high_priority_tasks,
                ),
                condition=self.has_tasks,
            ),
        )

    ...
```

## What is Loomi?

**Loomi changes how Python apps work - control flow and state become one thing through composable, declarative, state-bound operations.**

**This means:**
1. Build apps from basic operations - functions, sequences, loops, and more
2. Combine apps to make bigger apps
3. Operations are bound to state they need to make decisions - choosing paths, repeating steps, etc

**You get:**
1. 10x easier to design and build complex apps
2. 10x easier to maintain and extend apps
2. 10x upgraded robustness and reliability

**Superpowers included:**
- Concurrency out of the box without spaghetti code
- Resumable, reproducible executions with persistent fast state
- UI to visualize executions and state
- Debugging and profiling tools
- LoomiSTD and LoomiVerse - a collection of reusable apps

## When to use Loomi?

Complex decisions need state and easy-to-understand control flow. 

Loomi is the perfect fit for:
- **AI Agents**: LLM agents need shared context. With traditional code, you'd spend 50% of your time just passing state between agents. Loomi eliminates this boilerplate.
- **Financial Systems**: Risk calculation examining multiple factors often turns into nested if-else spaghetti. Loomi keeps your code readable with declarative branches that know which state to check.
- **Data Pipelines**: Validation that finds anomalies typically requires duplicated state tracking. Loomi's operations bind directly to the exact data points they need.
- **ML Workflows**: Adaptive training usually means rebuilding state between runs. Loomi persists state automatically, reducing restart code by 80%.
