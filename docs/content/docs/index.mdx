The interaction primitive. Build apps in one primitive that spans your whole stack (databases, UIs, AI agents, and services). No glue. 50x less code.

Every app is a set of interactions between systems. Nu makes interaction the primitive: **Refs** name what you touch (a UI widget, an LLM endpoint, a memory slot, a KV slot), **Interactions** describe what to do with them (read, write, branch, iterate, compose). Persistence, reactivity, atomicity, observability, and scalability are inherent, not bolted on.

Here is a complete Nu program:

```python
import nu, asyncio

tree = nu.ForeverDo(nu.print("tick") >> nu.Delay(1.0))
asyncio.run(nu.arun(tree))
```

You described a tree of what to do. Nu ran it. Every second it prints `tick`, forever, until you stop it.

## What you get

Inherent to the model, not bolted on:

- **Persistence.** State survives restarts, no database code.
- **Reactivity.** Reads recompute, UI updates.
- **Atomicity.** Any subtree runs as a transaction.
- **Observability.** Every node is a value you can print.
- **Scalability.** Swap the Fabric, same tree runs local or distributed.

## Use cases

- **AI agentic systems.** Refs for tools, memory, LLMs; Interactions for the loop.
- **Personal apps.** Persistent state, live UI, background loop, in a handful of lines.
- **Data-intensive apps.** Billions of entries in-process, reactive and atomic by default.
- **Enterprise in-house tools.** Dashboards and workflows over existing systems, same program from prototype to scale.
