Assemble software, don't write it. Nu is a Python programming model for live software: persistent state, reactive UI, and background loops that keep running while people use the app.

Here is a complete Nu program:

```python
import nu, asyncio

tree = nu.ForeverDo(nu.print("tick") >> nu.Delay(1.0))
asyncio.run(nu.arun(tree))
```

You described a tree of what to do. Nu ran it. Every second it prints `tick`, forever, until you stop it.

## What you get

- [Persistent state](/docs/tutorials/counter) that survives restarts, no database code to write.
- [Reactive UI](/docs/tutorials/movies) wired to that state, updates without a refresh.
- [Background loops](/docs/tutorials/hello) composed with `>>` and `|`, not with threads and queues.
- [One tree, many backends](/docs/tutorials/movies): swap memory for disk, local for distributed, same program.
- [Inspectable](/docs/tutorials/hello) end to end, every step of the tree is a value you can print.
