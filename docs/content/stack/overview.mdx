# The Loomi Stack

## 🛠️ LoomiSTD

Ready-to-use implementations for common needs.

LoomiSTD includes:
- Storage backends
  - File storage
  - In-memory storage
  - LMDB storage
- Execution engines with operations
  - Async executor implementation (aexecutor)
  - Atom operations (Function, App)
  - Flow control operations (Sequence, Loop, Parallel, Branch)
  - Timing operations (Delay, Timeout, Retry)
  - Collection operations (Map)
  - Reactive operations (Subscribe)
- Higher-order operations
  - ReactiveMap
  - DelayedFunction
  - etc
- Serialization formats
  - JSON codec 
  - Binary codec
