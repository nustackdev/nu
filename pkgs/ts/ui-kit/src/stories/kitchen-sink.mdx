# Kitchen Sink

A kitchen sink page shows every component in every state on one page, light and dark side by side. It is not documentation: open a component's own story for its API. It is for eyeballing consistency, after a token change or a component restyle, so a hover tone, a surface fill or a border that drifts from its siblings shows up next to them.

## Pages

- **Controls**: buttons, icon buttons, fields, choices, keys.
- **Surfaces**: cards, panels, type, markdown, code, tables, stats.
- **Feedback**: alerts, badges, status pills and dots, progress, spinners, empty states.
- **Navigation**: tabs, nav links, breadcrumbs, accordion, collapsible, tree.
- **Overlays**: menus, palette, popover, select, combobox, date picker, tooltip, dialog, sheet, all open.
- **Tables**: the display table, the data table and the markdown table, every variant and density, data tables live.
- **Charts**: every chart with all 8 categorical slots.
- **Layout: Grid, Line**: grids at every column count, inline runs of text, links, badges and keys wrapping like a paragraph.

## How the two themes render

The page's `<html>` is pinned to light, and the right column carries the `.dark` class, which re-resolves every token for its subtree. Overlays portal to `<body>` and would escape that column, so the Overlays page frames each one twice, a whole document per theme.

## Refs

The **Refs** stories are the other half: each draws a ref (ListRef, Row, Grid, ...) the way a program does, by writing chains into the real tree store and rendering the root with `NodeView`, light and dark side by side. In the browser a ref is drawn by its registered node, so the kitchen sink checks the looks and the refs check the wiring. They use the harness in `stories/refs/harness.tsx`, one story file per ref and one root segment per story.

## Pages

The **Pages** stories are whole pages (dashboard, detail, catalog, settings, landing) as a Python program draws them: a recorded run replayed through the same store and registry, one page per story at window width, in the toolbar's theme. They show what the kit composes into, not every state.
