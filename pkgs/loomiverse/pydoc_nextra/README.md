# pydoc_nextra 📚

This is a nifty little tool that turns Python docstrings into beautiful MDX docs for Nextra. 

What it does:

- 🔍 Scans Python modules automatically
- 📝 Parses Google-style docstrings
- 🎨 Generates pretty MDX with Nextra components (Cards, Callouts, Tabs)
- 🧭 Creates navigation structure automatically
